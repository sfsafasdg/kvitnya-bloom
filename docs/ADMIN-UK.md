# Як користуватися сайтом (для власниці)

## Вхід

1. Відкрийте **https://ваш-сайт.com/admin**
2. Введіть **пароль** (його дає той, хто налаштував сайт)
3. Більше нічого складного — без GitHub і без «Sanity»

---

## Що натискати

| Кнопка | Навіщо |
|--------|--------|
| **Додати товар** | Назва, ціна, фото з телефона → **Зберегти на сайті** |
| **Усі товари** | Натиснути на букет → змінити ціну або фото |
| **Замовлення** | Телефон клієнта, дата і час; статус «Нове» → «Виконано» |
| **Магазин** | Телефон, адреса, години, Instagram |

Після **Зберегти** зміни на сайті з’являться за хвилину.

---

## Для розробника (один раз)

У `.env.local` і на **Vercel**:

- ключі Sanity (як раніше)
- **`ADMIN_PASSWORD`** — простий пароль для `/admin`

Технічна адмінка Sanity (`/studio`) — лише для розробника; клієнтці давайте **`/admin`**.
