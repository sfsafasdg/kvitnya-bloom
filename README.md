# Bloom Flowers — frontend-концепт

Інтернет-магазин квітів у Білій Церкві. Головна сторінка — каталог товарів одразу після відкриття.

## Запуск

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)

## Маршрути

| Шлях | Опис |
|------|------|
| `/` | Каталог на головній + блоки про магазин |
| `/catalog` | Каталог з боковими фільтрами |
| `/product/[slug]` | Сторінка товару |
| `/cart` | Кошик |
| `/checkout` | Оформлення (демо) |

Дані магазину: `src/data/store.ts`
